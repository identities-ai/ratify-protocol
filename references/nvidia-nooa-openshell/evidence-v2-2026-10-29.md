# NVIDIA NOOA + OpenShell reference: Protocol v2 on the unified Python package (2026-10-29)

This record covers a re-run of the deterministic gate and of the live
OpenShell profile after the Python v2 SDK moved into the `ratify-protocol`
distribution: Protocol v2 is now `ratify_protocol.v2`, installed with the
`protocol-v2` extra, in place of the separate `ratify-protocol-v2`
distribution. The earlier v2 records are unchanged and kept as dated history:
[`evidence-v2-2026-10-27.md`](evidence-v2-2026-10-27.md) (the separate
`ratify-protocol-v2` 2.0.0b1 build) and
[`evidence-v2-2026-10-22.md`](evidence-v2-2026-10-22.md) (the in-tree alpha.1
build).

**Status: pre-release.** Both runs used the v2 SDK built from this repository
checkout (`ratify-protocol` 2.0.0b1 with the `protocol-v2` extra, and
`ratify-protocol-native-v2` 2.0.0b1), not published packages. It must be
repeated against the published `2.0.0-beta.1` packages
(`RATIFY_SDK=published`, after resolving the `TODO(RATIFY_V2_PIN)` markers)
before this reference is described as tested on a released v2. The receiver's
claim store, receipt log, checkpoint, journal and challenge issuance store are
the SDK's in-memory reference stores: development only.

- Branch `feat/python-unified` at `481a45f` (the commit that records this run
