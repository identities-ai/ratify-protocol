# Public symbol allowlist for verifyclient/...
#
# Every exported identifier of these packages (type, function, constant,
# variable, method, struct field) must be listed here;
# TestExportedSymbolsMatchAllowlist fails on any exported symbol that is not
# listed and on any listed symbol that no longer exists.
#
# Scope: the file formats customer tools exchange with Ratify Verify, the
# stateless checks on them, and the customer-run status bridge. Challenge
# issuance, managed signing, status publication on the service side and
# publisher leases are not part of these packages. Adding a line is a public
# API change and is reviewed as one. These packages are experimental until
# 2.0.0 (see doc.go).
